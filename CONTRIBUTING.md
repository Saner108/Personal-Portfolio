# Contributing

Thanks for your interest in improving this project.

## How to contribute

1. Fork the repository and create a branch for your change.
2. Keep changes focused and minimal.
3. Run `npm run build` to verify the project still builds.
4. Open a pull request with a clear summary of what changed and why.

## Reporting issues

If you find a bug or have an improvement suggestion, please open a GitHub issue with:

- Expected behavior
- Actual behavior
- Steps to reproduce
- Screenshots or logs (if helpful)
